# 荒野建国 · Wilderness Nation

> **3~7 个人，一块空地，一起把"国家"这件事做出来。**
>
> Minecraft 1.21.1 · NeoForge · Java 21 · 私人服务器

---

## 这是什么

一个**合作建造 + 冒险开拓**的整合包。你们从落地那天开始，选址、活下来、圈下第一块国土、分工、修路通电、出海远征、抵御入侵——最后留下一项属于你们自己的公共工程。

它不是"加了一堆 mod 的生存包"，也不是"NPC 替你建国的模拟经营"。**这个国家是你们亲手建的**：每一块砖、每一条规矩、每一次谁出料谁施工的账，都是玩法本身。

## 世界设定：你们是回归者

这片土地曾经有过一个文明（**旧世**），它留下了道路、界碑和埋在地下的**残破图纸**——然后在某个时刻崩了，原因不明。

它留下两样东西。**尸潮**：周期涌来的浪潮，不是军队而是潮水，**它们只会被活人吸引**，所以散居的人会被逐个淹没。**深渊**：它不追人，它**同化土地**，把墙和土壤变成自己的一部分。

你们是回到这里的人。**1500 年是你们的元年。**

于是"建国"不是任务清单上的一条，而是这片土地的物理规则：**聚集才安全，分工才能守住，修路才能扩张。** 而时间**只跟着你们实际上线的时间走**——你们不在，历史就不往前。

## 核心循环：六个时代

| 时代 | 在做什么 | 卡点 | 里程碑 |
|---|---|---|---|
| **1500 · 落地** | 一起选址、活下来、第一间避难所 | 安全 | 全队活着过第一晚 |
| **1505 · 立国** | 圈下第一块国土、出现分工、建起公共仓库 | **协调**：谁管仓库、谁定规矩 | 领土标记 + 公共仓库 + 约定落纸 |
| **1510 · 基建** | 修路、通第一条自动化、起第一座公共建筑 | 从"人肉搬运"转为"有东西自己会跑" | 第一件事不用人管 |
| **1515 · 出关** | 组队远征，去危险的地方抢国力材料 | 风险与收益的取舍、掉队与救援 | 第一次远征带回关键材料 |
| **1520 · 御敌** | 威胁来袭，城墙与协防终于有意义 | 袭击规模随国力上升 | 守住一次大规模袭击 |
| **1525 · 文明** | 大型公共工程、维度级冒险 | 规模化后的性能与秩序 | 完成毕业工程 |

**毕业不是终点，而是存档点**：时代继续走（无尽纪元），目标从"往上爬"变成"往外扩"——无尽工程、图鉴与收藏、建筑目录，以及每纪元一次的结算与碑林。碑林越长，越舍不得走。

## 六个特色

**1. 你们活在一个会变老的世界里：1500 年开局**
开局是 **1500 年**，时间**只跟着你们实际在线的时间走**（没人上线，世界就不变老）。每 5 年一个时代，时代时长**递增**（12 / 20 / 25 / 25 / 30 / 38 小时），**全程约 150 小时 ≈ 3.5~7 个月毕业**。时代决定"内容开放到哪"：图纸、模块、维度、任务章。

时代推进靠**「时间到」或「做完并主动加速」**，取先到者——所以永远不会被锁死，做完也能主动跳。每个时代都有一个**终局大任务**，而它的作用是「**用一次低成本的彩排，教会下个时代的玩法**」。

**2. 领地即国土**
队伍与领地是"国家"的物理形式。谁能在哪建造、破坏、开箱子，都是规则而不是人情——**靠信任撑不过第一周**，这是这类包唯一能长期活下去的机制。

**3. 图纸与工程制：标准件打印，地标手建**
公共设施（仓库、农田、熔炉阵列、城墙、店铺、传送节点）可以用图纸标准化建造，材料真实消耗；但**地标必须手建**——议事厅、各人的家、纪念碑、毕业工程。标准件换效率，地标留感情。

工程制把"贴图纸"变成协作：**发起工程 → 众人认捐材料 → 施工 → 完成记入国策**。谁贡献了什么，有账可查。

**4. 威胁随国力生长，而城墙是真工事**
袭击的**类型**随时代变化，**规模**随国力上升；而敌人**真的会拆墙**——拆迁档位从"玻璃泥土"一路升到"含黑曜石"。于是"玩家建更强的墙、世界派更强的拆迁队"成为一条持续到毕业的工事升级线。

还有一条别处没有的战术：袭击**围绕在场的玩家生成**（不是朝坐标推进），所以**你可以引怪**——把袭击引向别处，甚至引向敌对据点。

**国力也可以变成刀：一支你们自己的军队。** 从时代 3 起可以带护卫出门，到**御敌时代**军队变成必需品——因为此时的袭击规模已经跟着国力涨上来了。工事负责"不被拆穿"，军队负责"机动补位与反推"，**两条线都要投国力**，于是"把资源投进墙里还是投进兵里"成为真实的取舍。指挥是**指挥轮盘与指挥杖**（第一人称下就能用，不需要切视角），兵种有相克关系，攻城器械走 Create 产线自己造。

而边界很清楚：**军队可以被指挥，但建造不外包**。这个包的定义是"每一块砖都是你们自己放的"——NPC 不会替你们盖房子，也不会替你们定规矩；军队要吃饭、要装备、要有损耗，养不起就带不动。**没有"挂机看 NPC 打完"这种设计。**

**而威胁是有来源的，所以你们可以反击。** 袭击不是凭空刷出来的——**原版的袭击本来就从掠夺者前哨站发起**，所以"敌人在世界上有据点"这件事不需要编。于是形成一条**攻守转换**线：时代 3 **探明据点** → 时代 4 **挨打之后能反击**（清剿据点会**降低**袭击压力，这是全包第一次给玩家"掐断来源"的手段）→ 时代 5 **成建制攻城**（带上军队与攻城器械拔掉要塞级据点）。据点会被**重新占据**、减益**有上限**，所以它不是一次性清完就没事，而是长期的拉锯——这也正是"从守土到开疆"的转折点。

**5. 冒险为建造服务**
危险地区的稀有产物是国力升级的燃料：**要建 X，就得去 Y**。高阶图纸本身就是战利品。两条线不是并列的两个模块，而是互为因果。

**6. 谁破坏都能回滚，而规则只有一页**
方块改动全程记录，误拆能恢复，故意破坏有据可查；回滚权限只收在 1~2 个人手里，避免"人人能回滚"变成互相报复。

而这个包**不设任何职位**：朋友之间不需要官职——头衔会把一起玩变成上班。责任跟着具体的事走：**谁发起工程谁负责那件事，谁敲钟谁定集结点**。需要写下来的只有一页约定。**多人服的安全感来自"能回滚"和"有说法"，不是来自"大家都很好"。**

## 服务器约定（要点）

- **白名单 + 领地权限**：不是可选项，是玩法的一部分
- **备份**：停机或 `save-off` 后做；**定期验证备份真的能恢复**——只备份不试恢复等于没有备份
- **投影可以，自动放置不行**：允许用投影辅助建造；**禁止自动放置类功能**（服务端不执行、且可能被反作弊判定为作弊）
- **公共工程区与私人区分开**：否则一贴图纸就覆盖别人的地
- **有公约**：职责（谁管仓库/权限/备份）、处置（误破坏怎么恢复）、离服（建筑物资归谁）、新增（中途加入从哪接入）

## 这个包不做什么

1. **不做 PvP 战争服** —— 默认玩家之间不互相破坏，"战争"是打环境与怪物
2. **不按数量堆 mod** —— 旧稿写的是"不做 200+ 大杂烩"，但那是**没有测量手段时的替代品**；现在 TPS / MSPT / 实体上限 / 启动时间都能自动测，约束改成**指标**（`DESIGN.md` §12）。真正的红线是**无意义堆砌**：同一功能位只留一个（配方查询、地图、存储各选一）
3. **不做 NPC 替你们建国** —— 自动化只用来干重复劳动，不用来代替"国家"本身
4. **不做单人挂机包** —— 没人上线时服务器就是空的，这是取舍不是缺陷

## 怎么加入（客户端）

> ⚠️ **现在还不能装**：mod 清单虽然定案了 180 条，但**还没装进 `pack/`**（那里目前只有 packwiz 骨架）。等第一批装完并实测通过后，这一节会换成实测过的步骤。

大致流程（packwiz 标准做法）：

1. 装一个 **1.21.1 + NeoForge 21.1.250** 的实例——**版本要与包完全一致**，否则连不上服
2. 下载 `packwiz-installer-bootstrap.jar`
3. 同步一次（会增量拉取 mod）：

```powershell
java -jar packwiz-installer-bootstrap.jar -g -s client "https://raw.githubusercontent.com/142093601/wilderness-nation/main/pack/pack.toml"
```

> 国内若连不上 `raw.githubusercontent.com`，把前缀换成 jsDelivr 镜像
> `https://cdn.jsdelivr.net/gh/142093601/wilderness-nation@main`（两条都已实测可达）。

4. 以后每次开游戏前跑一次这条命令即可**增量更新**，不用手动下 mod

服务端同理：把 `-s client` 换成 `-s server`。

## 第三方 mod 的署名与许可

本包**不重新分发任何 mod 文件**：`pack/` 里只存**元数据**（`mode = "metadata:modrinth"` / `"metadata:curseforge"`），
由安装器从原作者的分发渠道（Modrinth / CurseForge）按需下载。所以每个 mod 的许可与收益都归原作者。

**特别署名（该 mod 的使用条款要求署名作者与来源，且禁止盈利）**：

- **Hundred Years Warfare**（`hundred-years-warfare`）—— 本包"带兵打仗"机制的核心 mod。
  作者与来源见其 [Modrinth 项目页](https://modrinth.com/mod/hundred-years-warfare)。
  条款原文要点：**允许放进整合包，但需署名作者与来源、不得盈利**；本包为非商业私人服使用。
  该 mod 的工人/工作站玩法源自 **Ancient Warfare 2**，RTS 模式的摄像机实现参考 **Freecam**，
  攻城器械设计参考 **Age of Empires IV** —— 一并致谢。
- 完整清单与逐条证据见 **`MODLIST.md`**；机器可读清单见 **`modlist.tsv`**。
